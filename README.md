# Rexovas Homebrew Tap

```sh
brew install rexovas/tap/session-protect
```

Casks are maintained automatically by each project's release pipeline.

`session-protect` shipped as a formula up to v1.3.0 and as a cask since
v1.3.1; `tap_migrations.json` moves existing formula installs to the cask
on their next `brew update`.
